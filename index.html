About Neather

By players,
for players.

Neather Launcher is a free, reliable, and user-focused Minecraft launcher — built to give players a simple and trustworthy way to manage and play Minecraft. Independently developed with a focus on stability, performance, privacy, and a smooth user experience.

One place for version management, mods, resource packs, instances, and Minecraft customization tools — from 1.0 to the latest release. Free forever, no subscriptions, no paywalled features. Source code is proprietary and not publicly distributed.

Independently created and maintained by Shahriar Mahmud — built on testing, user feedback, and what the community actually needs.
